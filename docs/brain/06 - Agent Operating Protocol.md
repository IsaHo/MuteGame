# قرارداد کار Codex و Claude Code

## قبل از هر کار

1. `PROJECT_BRAIN.md` و این فایل را بخوان.
2. `02 - Current State.md` و سند دامنه مرتبط را بخوان.
3. `git status` را بررسی کن؛ تغییرات کاربر را revert نکن.
4. هدف، معیار پذیرش و فایل‌های درگیر را در گزارش شروع بنویس.

## هنگام کار

- server منبع حقیقت مالی و نشست است.
- الگوهای موجود Qt/QML و API را حفظ کن.
- تغییر مالی بدون transaction، ledger و test ممنوع.
- UI ادمین باید متراکم و عملیاتی باشد؛ UI client می‌تواند سینمایی باشد.
- هر ۳۰ دقیقه یا پایان milestone گزارش کوتاه بده.

## بعد از کار

1. build و تست مرتبط را اجرا کن.
2. `02 - Current State.md` را فقط اگر وضعیت محصول تغییر کرده به‌روزرسانی کن.
3. تصمیم معماری را در سند مربوط ثبت کن.
4. یک entry کوتاه در `CHANGELOG.md` اضافه کن.
5. گزارش نهایی شامل فایل‌ها، تست‌ها، ریسک باقی‌مانده و commit باشد.

## قالب گزارش عامل

```text
هدف:
انجام‌شده:
فایل‌ها:
تست‌ها:
تصمیم‌ها:
ریسک/کار بعدی:
```

## صرفه‌جویی توکن

- اطلاعات پایدار را در Brain بنویس، در prompt تکرار نکن.
- گزارش‌ها نتیجه و تصمیم را ثبت کنند، نه مکالمه و reasoning طولانی.
- Agent فقط سند دامنه مرتبط را بخواند.
