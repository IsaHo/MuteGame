# سیستم طراحی

## شخصیت برند

MuteGame باید حس «arena premium» بدهد: سریع، دقیق، قدرتمند و اجتماعی. ظاهر آن نباید شبیه پنل‌های قدیمی cyber cafe یا داشبوردهای بنفش تکراری باشد.

## Client

- پس‌زمینه تیره خنثی با تصاویر واقعی بازی‌ها.
- رنگ‌های برند محدود به accent و state؛ تصویر بازی رنگ اصلی صحنه را می‌سازد.
- header پایدار: زمان، اعتبار، بدهی، وضعیت شبکه و حساب.
- navigation کم‌عمق: خانه، بازی‌ها، برنامه‌ها، شاپ.
- بازی‌ها poster-first با title خوانا و وضعیت نصب/اجرا.
- motion کوتاه 120 تا 220ms؛ بدون animation دائمی مزاحم.

## Admin

- density بالا، heading کوچک، grid قابل اسکن.
- Floor Console صفحه پیش‌فرض.
- جدول برای حسابداری و گزارش؛ card فقط KPI یا station.
- shortcut و context menu برای اپراتور حرفه‌ای.
- عملیات مالی با مبلغ، روش پرداخت، کاربر و نتیجه واضح.

## تایپوگرافی

- فارسی: Vazirmatn.
- عدد/لاتین: Inter.
- hero فقط در login/client home.
- عدد مالی از متن توضیحی برجسته‌تر ولی بدون font عظیم.

## وضعیت‌ها

| وضعیت | رنگ | کاربرد |
|---|---|---|
| سالم/وصول | سبز | آنلاین، پرداخت‌شده |
| اطلاعات | فیروزه‌ای | پیام، شبکه |
| هشدار | کهربایی | زمان کم، بدهی تازه |
| بحرانی | قرمز | قطع، بدهی معوق، خطای مالی |

## قواعد QA

- 1280×720، 1920×1080 و scale 125% Windows.
- متن فارسی و مبلغ از container خارج نشود.
- focus keyboard، hover، loading، empty و error state.
- هیچ action مالی فقط با icon بدون tooltip یا label نباشد.
